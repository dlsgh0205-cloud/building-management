깃허브 배포 성공! (설정 필요)

현재 깃허브(GitHub) 환경에 정상 배포되었습니다. 예전에 하얀 화면만 나왔던 이유는 클라우드 데이터베이스 연결 설정이 누락되어 자바스크립트가 멈췄기 때문입니다.

HTML 파일 단독으로는 보안상 구글 스프레드시트에 직접 데이터를 자동 저장할 수 없습니다. 따라서 실시간 동기화를 구현하려면 구글 파이어베이스(Firebase)라는 무료 백엔드 설정이 필수입니다.

// 1. 구글 파이어베이스 가입 후 프로젝트 생성
// 2. index.html 하단 스크립트의 manualFirebaseConfig 에 값 입력

const manualFirebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "your-app.firebaseapp.com",
  projectId: "your-app",
  storageBucket: "your-app.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};

코드 하단의 설정을 완료하면 이 화면은 사라지고 정상 작동합니다.
